# 圈圈叉叉：在线井字棋

一个双人网页井字棋。创建房间后，把邀请链接或房间号发给朋友即可对战。

## 在本机运行

需要安装 Node.js 18 或更新版本（推荐使用当前 LTS 版本）。在项目目录打开终端，运行：

```bash
npm install
npm start
```

打开 <http://localhost:3000>。可以用两个浏览器窗口测试：一个创建房间，另一个通过邀请链接或房间号加入。

本机的 localhost 链接只能在自己的电脑访问。要邀请其他网络的朋友，先按下面的方法部署。

## 部署到 Render

1. 将本项目上传到 GitHub 仓库，`node_modules` 不需要上传。
2. 登录 [Render](https://render.com/)，新建 **Web Service**，连接该 GitHub 仓库。
3. 选择 Node 环境，构建命令填 `npm install`，启动命令填 `npm start`。
4. 创建服务并等待部署完成，打开 Render 提供的网址。创建房间后，将邀请链接发送给朋友。

其他支持运行 Node.js 和 WebSocket 的平台也可以使用，构建和启动命令相同。请在部署前查看平台当时的价格、免费额度和休眠规则。

## 游戏说明

- 房间最多两人，X 先手。服务器负责验证落子并判断胜负。
- 结束后双方都点击“再来一局”即可重新开始。
- 玩家断线或离开后，棋盘会重置；可重新加入仍存在的房间。双方都离开时房间被删除。
- 房间保存在单个服务器进程的内存中，重启或休眠会清空房间。部署时使用单个实例；多实例需要额外的共享存储和 Socket.IO 配置。
